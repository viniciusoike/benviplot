# Get available Poppins font variants

Lists all available Poppins font variants (weights and styles) installed
on the system. Useful for advanced font customization.

## Usage

``` r
get_poppins_variants()
```

## Value

A character vector of available Poppins variants, or `NULL` if Poppins
is not installed.

## Examples

``` r
if (FALSE) { # \dontrun{
# List available Poppins variants
get_poppins_variants()
} # }
```
