# QuintoAndar Index data

A subset of data from the QuintoAndar rent index

## Usage

``` r
iqa
```

## Format

### iqa

A data frame

- name_muni:

  Name of the municipality (city)

- ts_date:

  Date of the observation

- rent_m2:

  Observed median rent

- wrent_m2:

  Weighted observed median rent

- wgt_inc:

  Income weight

- chg:

  Monthly percent variation of the index

- acum12m:

  12-month accumulated variation of the index
